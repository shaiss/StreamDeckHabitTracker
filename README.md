# Stream Deck → Habit Tracker

Tap a physical Stream Deck key → a timestamped row lands in your Google Sheet.
No always-on server, works even when your PC is asleep (the logging lives in
Google's cloud).

**Your sheet:** [Habit Tracker (Stream Deck)](https://docs.google.com/spreadsheets/d/12NJW-TmsR0zyZdYiAl1LG3IZ7WqGXivGmz8v-HkqxhI/edit)

Each button sends a tiny web request to a Google Apps Script "web app" attached
to that sheet. The script writes a row: timestamp, habit, date, time.

## The only two things a computer can't do for you

Both are clicks, not coding — and together they take about 5 minutes:

1. **Deploy the script** — Google *requires* you to click through its own
   authorization screens in a browser. There is no API that bypasses this.
2. **Install the Stream Deck plugin** — one click from the Marketplace.

Everything in between is generated. Follow the steps below once and you're done.

---

## Step 1 — Deploy the logger (~4 min, one time)

1. Open the [sheet](https://docs.google.com/spreadsheets/d/12NJW-TmsR0zyZdYiAl1LG3IZ7WqGXivGmz8v-HkqxhI/edit).
2. **Extensions → Apps Script**. A code editor opens in a new tab.
3. Delete whatever's in `Code.gs` and paste in the contents of
   [`apps-script/Code.gs`](apps-script/Code.gs). Click **Save** (💾).
4. **Deploy → New deployment** → gear ⚙ next to "Select type" → **Web app**.
5. Set:
   - **Execute as:** **Me**
   - **Who has access:** **Anyone**  ← required so the Stream Deck can reach it
6. **Deploy** → **Authorize access** → pick your account → on "Google hasn't
   verified this app" click **Advanced → Go to (project) → Allow**. (It's your
   own script; this is normal.)
7. Copy the **Web app URL**. It ends in `/exec`:
   `https://script.google.com/macros/s/AKfyc..../exec`

**Test it:** paste `<your-exec-url>?habit=Test` into a browser. You should see
`Logged: Test ...` and a new row appear in the sheet.

## Step 2 — Generate your buttons (~10 sec)

With [Node](https://nodejs.org) installed, from this folder run:

```bash
node tools/generate.mjs "https://script.google.com/macros/s/AKfyc..../exec"
```

(Use *your* `/exec` URL in quotes.) This writes two things into `dist/`:

- **`urls.txt`** — the exact URL for every button. The 100%-reliable path.
- **`Habit Tracker.streamDeckProfile`** — a double-click-to-import profile.

Options: add `--key=yourword` if you set a secret (see below), and
`--model=xl|mini|original|mk2|any` to match your hardware (default `mk2`, the
standard 15-key Stream Deck).

## Step 3 — Put them on the Stream Deck (~1 min)

1. In the Stream Deck app, open the **Marketplace** (shopping-bag icon) and
   install **"Web Requests"** by *data-enabler*. (This is the plugin that fires
   the request silently — the built-in "Website" action would pop a browser tab
   every tap.)
2. Now either:
   - **Import the profile:** double-click `dist/Habit Tracker.streamDeckProfile`
     (or Stream Deck app → profile dropdown → **Import**). Done. *If your Stream
     Deck version refuses the import, just use the manual path — it's 5 URLs.*
   - **Or add buttons manually** from `dist/urls.txt`: drag a **Web Request →
     HTTP Request** action onto each key, set **Method: GET**, paste the **URL**,
     and set the **Title**.

## Step 4 — Plug in the Stream Deck and tap

A row appears in the **Log** tab on every tap. That's it.

For counts, charts, and daily views, see [`sheet/dashboard.md`](sheet/dashboard.md).

## Customizing your habits

Edit [`config/habits.json`](config/habits.json) — each entry is
`{ "emoji", "label", "name" }` where `name` is what gets logged. Then re-run
Step 2. Keep `name` to a single word (spaces are URL-encoded automatically, but
single words are cleanest).

## Optional: lock it down with a secret

Anyone who guesses your `/exec` URL could write junk rows. To prevent that:

1. In `apps-script/Code.gs`, change `const SECRET = 'CHANGE_ME';` to a random
   word, e.g. `'k9x2q'`. Save.
2. Redeploy the change: **Deploy → Manage deployments → edit (✏️) → Version: New
   version → Deploy** (the `/exec` URL stays the same).
3. Re-run the generator with `--key=k9x2q`. Every URL now carries `&key=...`.

For a personal tracker it's fine to skip this.

## Troubleshooting

- **Button does nothing / no row:** open the button's URL directly in a browser.
  If that fails, the deployment access isn't "Anyone" — redeploy (Step 1.5).
- **`Unauthorized`:** your URL is missing `&key=...` but the script has a SECRET
  set. Re-run the generator with `--key=...`, or reset SECRET to `CHANGE_ME` and
  redeploy.
- **Wrong times:** set the sheet's timezone via **File → Settings → Time zone**,
  then redeploy the script.
- **Changed `Code.gs` but nothing updated:** you must publish a **New version**
  under Manage deployments (see the secret steps above).
- **Profile won't import:** Stream Deck's profile format varies by version — fall
  back to the manual URLs in `dist/urls.txt` (Step 3, second bullet). Same result.

## Advanced: deploy from the CLI with clasp

Prefer not to touch the Apps Script editor? You can push and deploy with
Google's [`clasp`](https://github.com/google/clasp) CLI instead of Step 1:

```bash
npm i -g @google/clasp
clasp login                      # opens a browser once
clasp create --type sheets --title "Habit Tracker" --rootDir apps-script
clasp push
clasp deploy --description "habit logger"
```

You'll still get the one-time browser authorization the first time the web app
runs, and you'll need to set **Who has access: Anyone** for the deployment in the
Apps Script UI (clasp can't set anonymous web-app access). For most people the
5-minute manual Step 1 is actually less fuss — this path is here if you want it.
